# muse-gpsshortcut-entry

Entry for the make.fun competition [The GPS Swears It Was a Shortcut](https://make.fun/bounty/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9).

## The entry

> That was not a wrong turn, that was a shortcut through a corn maze, a cul-de-sac and Mrs Patel's driveway - the map said scenic, and frankly, you needed the tour.

Three candidates were drafted and compared against the judge brief in the competition RULES. Selection reason: A smug GPS blames the map for a scenic shortcut through a corn maze, a cul-de-sac and a named driveway, closing on 'you needed the tour'.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) writes the fixed text to `entry.txt` (sha256 c4e983263044ed3ac635a8bcff99c1aeeb91efa8192e20e8f2c021c73a43b803).
